# MBIL Website

Website for the **Musculoskeletal Biomechanics & Imaging Laboratory (MBIL)** —
School of Kinesiology, University of Michigan. PI: David B. Lipps, Ph.D.

Built with [Astro](https://astro.build) 5 + Tailwind CSS v4 and deployed to
GitHub Pages at **https://mbil-umich.github.io/** via GitHub Actions on every
push to `main`.

## Local development

```sh
npm install        # install dependencies
npm run dev        # dev server at http://localhost:4321
npm run build      # static build to dist/
npm run check      # Astro type check
```

See [`CLAUDE.md`](./CLAUDE.md) for the design system, project structure, and
content conventions.
